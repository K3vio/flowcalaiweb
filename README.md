# FlowCalAI 📅

Ever struggled to fit everything into your week without conflicts? Use FlowCalAI.

FlowCalAI is a web application that helps university students organise their weekly schedules. Instead of treating every event the same, it separates fixed and flexible schedules, detects clashes, and uses AI to suggest better time slots when conflicts occur.

Features
- Weekly calendar view
- Add fixed and flexible schedules
- Detect schedule conflicts
- AI-powered scheduling suggestions
- Clean and easy-to-use interface

Tech Stack
- HTML
- CSS
- JavaScript
- Gemini API

Getting Started
1. Clone the repository
2. git clone https://github.com/K3vio/FlowCalAI.git
3. cd FlowCalAI
4. Run the project

The project doesn't require any installation.

Simply open index.html in your browser.

For the best experience, we recommend using Live Server in Visual Studio Code:

1. Open the project in VS Code.
2. Install the Live Server extension if you don't already have it.
3. Right-click index.html.
4. Select Open with Live Server.
